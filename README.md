# HandyNotes: Homestead

Housing decor vendor pins for your world map and minimap, as a lightweight
[HandyNotes](https://www.curseforge.com/wow/addons/handynotes) plugin.

Hover a pin to see the vendor's wares. Click a world-map pin to set a
waypoint.

Powered by the same verified vendor data as
[Homestead](https://www.curseforge.com/wow/addons/homestead). If you want
collection tracking, ownership-aware tooltips, and the full toolset, install
Homestead; this plugin steps aside automatically when Homestead is enabled.

Requires HandyNotes.
